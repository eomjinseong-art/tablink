나두 탭링크 (Nadoo Tablink)

틱톡·쇼츠 댓글 링크 안 눌릴 때? 아이폰 뒷면 톡톡 두드려 바로 열기!

👁️ 누적 방문자 수: 불러오는 중...

💡 나두 탭링크(Nadoo Tablink)란?

틱톡이나 유튜브 쇼츠를 보다 보면 댓글창에 www.coupang.com/... 같은 구매 링크가 올라오지만, 앱 자체 제한 때문에 터치도 안 되고 복사도 안 되어 짜증 났던 경험 있으시죠?


나두 탭링크는 아이폰 뒷면을 톡, 톡 두 번 두드리는 것만으로 화면의 주소를 자동 인식하여 브라우저로 1초 만에 연결해 주는 무료 자동화 프로젝트입니다!

🛠️ Step 1. 파이썬 서버 배포하기 (Vercel)

1단계 백엔드

컴퓨터에 폴더를 만들고 아래 코드를 그대로 저장하여 GitHub를 통해 Vercel에 올려주기만 하면 됩니다.

# api/index.py
from flask import Flask, request, jsonify
import re

app = Flask(__name__)
URL_PATTERN = r'(https?://[^\s]+|www\.[^\s]+|[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}/[^\s]*)'

@app.route('/api/extract-link', methods=['POST'])
def extract_link():
    try:
        data = request.get_json(silent=True) or {}
        raw_text = data.get('text', '')
        urls = re.findall(URL_PATTERN, raw_text)
        
        if not urls:
            return jsonify({'success': False, 'message': '링크 없음'}), 404
        
        target_url = urls[0].strip()
        target_url = re.sub(r'[\),\.\?]+$', '', target_url)
        if not target_url.startswith(('http://', 'https://')):
            target_url = 'https://' + target_url
            
        return jsonify({'success': True, 'url': target_url})
    except Exception as e:
        return jsonify({'success': False, 'error': str(e)}), 500
🚨 초보자 흔한 실수 1: vercel.json 파일 생성 문제

루트 폴더에 vercel.json을 직접 만들면 Vercel 최신 시스템과 충돌하여 404 NOT_FOUND 에러가 납니다!

해결책: vercel.json 파일은 삭제하고, 오직 api/index.py 파일 구조로만 배포하세요. 최신 Vercel이 자동으로 알아서 실행해 줍니다.

📱 Step 2. 아이폰 단축어 완벽 설정 (가장 중요!)

아이폰에서 단축어를 만들 때 용어가 다르고 화면 위치를 찾기 힘드셨죠? 눈앞에 보이는 화면 그대로 순서대로 따라 해 보세요.

1. 새 단축어 만들기 및 스크린샷 설정
  1. 아이폰 기본 [단축어] 앱을 엽니다.
  2. 오른쪽 상단 + 버튼을 누릅니다.
  3. 맨 위 '새 단축어' 이름을 터치해 나두탭링크로 이름을 바꿉니다.
  4. 화면 맨 바닥에 붙어있는 검색창(돋보기 아이콘)을 누르고 스크린샷을 검색한 뒤 [스크린샷 찍기]를 누릅니다.
  5. 다시 맨 아래 검색창에서 텍스트 추출을 검색한 뒤 [이미지에서 텍스트 추출]을 선택합니다.
2. Vercel 서버 연결하기
  1. 맨 아래 검색창에 URL을 검색하고 기본 [URL]을 선택합니다.
  2. 추가된 블록의 주소 칸에 내 Vercel API 주소를 복사해서 넣습니다.
    예: https://tablink-ten.vercel.app/api/extract-link
  3. 맨 아래 검색창에 URL 콘텐츠를 검색하고 초록색 [URL 콘텐츠 가져오기]를 선택합니다.
  4. 추가된 블록 옆의 파란색 화살표 ( > )를 눌러 상세 옵션을 엽니다.
🚨 초보자 흔한 실수 2: Key/Value 값 설정 오류

이 부분에서 글자를 잘못 적으면 서버가 동작하지 않습니다!

  • 메서드: GET을 터치해서 POST로 변경
  • 본문 요청: 없음을 터치해서 JSON으로 변경
  • 새로운 필드 추가 터치 ➔ [텍스트] 선택
  • Key 부분 (빨간색 - 표시 왼쪽): 영문 소문자로 text 라고 직접 타이핑해 넣으세요. (기본 적힌 'key'라는 단어는 지워야 합니다)
  • Value 부분 (빨간색 - 표시 오른쪽): 'value'라고 적힌 글자를 지운 뒤 빈칸을 터치하면 자판 위에 떠오르는 파란색 버튼 중 [이미지에서 추출한 텍스트]를 터치하세요!
3. 파싱 및 브라우저 열기
🚨 초보자 흔한 실수 3: 'JSON' 검색이 안 돼요!

아이폰 한글 단축어 앱에서는 json이라는 명칭 대신 사전이라는 단어를 사용합니다!

  1. 맨 아래 검색창에 사전을 검색한 뒤 주황색 아이콘의 [사전 값 가져오기]를 누릅니다.
  2. 추가된 블록에서 파란색 글씨로 적힌 [키](또는 Dictionary) 부분을 터치하고, 소문자로 url 이라고 입력합니다.
  3. 맨 아래 검색창에 URL 열기를 검색해 파란색 [URL 열기]를 선택해 붙여줍니다.
  4. 오른쪽 맨 위 [완료] 버튼을 누르면 단축어 작성이 끝납니다!

👈 Step 3. 아이폰 뒷면 탭(Back Tap) 매핑

만든 단축어를 손가락 두드림 제스처에 연결하는 마지막 과정입니다.

  1. 아이폰 기본 [설정] 앱(톱니바퀴 모양)을 엽니다.
  2. [손쉬운 사용] ➔ [터치] 메뉴로 들어갑니다.
  3. 화면 맨 아래로 끝까지 내린 후 [뒷면 탭]을 누릅니다.
  4. [이중 탭]을 누릅니다.
  5. 목록을 아래로 끝까지 스크롤하여 [단축어] 소제목 아래에 있는 [나두탭링크]를 터치해 체크 표시(v)를 만듭니다.

🎉 완성! 이제 틱톡이나 쇼츠 댓글을 보다가 아이폰 뒷면을 톡톡 두번 두드리면 링크가 바로 사파리 브라우저로 짠! 하고 열립니다.
